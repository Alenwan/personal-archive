# Security policy

Personal Archive is an Alpha release. Security fixes are made for the current source release; older Alpha commits are not maintained as supported branches.

If GitHub shows **Security → Advisories → Report a vulnerability** for this repository, use it to send details privately. If that option is unavailable, open a public issue asking the maintainer for a private reporting channel, without including exploit steps, credentials, personal files, or sensitive logs. Please allow time to investigate before public disclosure.

Never attach a real `.env`, database dump, object-storage data, password, recovery key, or personal document to an issue. Share a minimal synthetic reproduction instead. The source installation is intended for a trusted household or controlled network, not an unreviewed public internet deployment.
